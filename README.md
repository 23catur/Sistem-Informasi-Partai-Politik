## 🧭 Overview

**Sistem Informasi Partai Politik (SIPP)** adalah aplikasi berbasis web untuk memfasilitasi pengelolaan data partai politik dan anggotanya secara digital, efisien, dan terstruktur. Dikembangkan menggunakan Laravel framework terbaru dengan fokus pada keamanan, kemudahan penggunaan, dan skalabilitas.

---

## 🚀 Key Features

✨ **Fitur unggulan yang siap digunakan:**

- 🏛️ **Manajemen Partai & Cabang** – Buat, ubah, dan kelola entitas partai politik.
- 👥 **Manajemen Anggota** – Tambah data anggota, status verifikasi, dan info lengkap.
- 📌 **Struktur Kepengurusan** – Input dan tampilkan struktur organisasi partai.
- 📎 **Upload Dokumen** – Unggah berkas terkait (KTP, SK, dsb).
- 📊 **Dashboard Statistik** – Lihat ringkasan data secara visual & interaktif.
- 🔐 **Autentikasi & Role-Based Access** – Akses dibedakan untuk Admin, Operator, dan Viewer.
- 🖨️ **Cetak & Ekspor PDF** – Generate laporan dalam bentuk siap cetak.
